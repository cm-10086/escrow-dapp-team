## 修复

- `useScaffoldEventHistory` 增加从最新区块向前分批读取历史的选项，保留向前实时监听；禁用查询时停止继续翻历史页，实时查询键包含网络、合约与区间，避免多个读取器共享错误游标。
- `/escrow` 通过 `useEscrowOrderHistory` 同时读取近期和较旧历史。近期固定窗口为首次进入时最近 1000 个区块，优先读取最新批次；较旧区间从部署区块补读。当去重事件数量达到已读取的 orderCount，暂停较旧区间，避免继续扫描无事件的空档。近期窗口之外的事件仍能由旧区间补读，不因窗口限制丢弃旧订单。
- 创建回执已证明存在的订单 ID 直接加入当前页面列表，随后读取真实 getOrder；不等待历史扫描完成，也不使用事前 orderCount 猜测订单号。
- 页面明确区分最新订单读取与后台补读历史。手动刷新近期事件和合约状态，旧区间失败时重试旧查询；成功的旧事件页无需每次重新查询。
